## About

This repository contains the complete learning package for **Agentic AI for Facebook Marketing (C526)** by Tertiary Courses / Tertiary Infotech Academy. It combines a concept-first slide deck, a self-contained Learner Guide, a timed Lesson Plan, and eight connected labs built around the synthetic **Harbour & Hearth** campaign scenario.

The course progresses from campaign strategy and evidence-grounded prompting to Facebook content, ad-copy systems, campaign design, performance diagnosis, governed operations, and bounded scaling. All public posting, messaging, targeting, and spend actions remain draft-first and subject to human approval.

### What you'll learn

| Topic | Focus |
|-------|-------|
| **1. Getting Started with Agentic AI for Facebook Marketing** | Facebook marketing systems, objectives, audiences, agent anatomy, prompting, and approval gates. |
| **2. Content Creation and Ad Copy with AI** | Message hierarchy, content pillars, Facebook copy, creative formats, brand rules, and quality review. |
| **3. Building and Optimising Ad Campaigns with AI** | Campaign hierarchy, audience strategy, budgets, placements, measurement, diagnosis, and controlled experiments. |
| **4. Automating and Scaling Facebook Marketing with AI Agents** | Scheduling, response triage, evidence-linked reporting, bounded optimisation, privacy, and incident safeguards. |

## Course Journey

```text
DAY 1 — Strategy, prompting, content, and creative
  Lab 1  Approved brand facts ─▶ campaign success brief
  Lab 2  Audience evidence ─▶ hypotheses + prompt contract
  Lab 3  Strategy pack ─▶ seven-day Facebook content system
  Lab 4  Message hierarchy ─▶ controlled copy + creative matrix

DAY 2 — Campaign design, performance learning, and governed automation
  Lab 5  Campaign decisions ─▶ campaign / ad set / ad blueprint
  Lab 6  Synthetic results ─▶ metric diagnosis + controlled test
  Lab 7  Approved operations ─▶ scheduling / triage / reporting runbook
  Lab 8  Guardrails + evidence ─▶ bounded optimisation and scale policy
```

Every lab produces a named checkpoint for the next lab. The final campaign pack links strategy, content, campaign structure, measurement, operations, approvals, and rollback evidence.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C526---Agentic-AI-for-Facebook-Marketing.git
cd C526---Agentic-AI-for-Facebook-Marketing
```

### 2. Review the concepts

Open the [Learner Guide](LG-Agentic%20AI%20for%20Facebook%20Marketing%20%28C526%29.md), then review the matching topic in the slide deck.

### 3. Complete the labs in order

Begin with [Lab 1](labs/lab-01-build-the-facebook-campaign-success-brief.md) and retain each named output in one `C526-campaign-pack/` folder. Use only the supplied synthetic resources unless your organisation separately authorises real data and account access.

### 4. Rebuild the courseware

From Git Bash on Windows:

```bash
COURSE_REPO="$(pwd)" bash ".agents/skills/non-wsq-courseware-build/build/build_courseware.sh"
```

The build regenerates the deck, Learner Guide, Lesson Plan, PDFs, and lab files from the shared course source.
